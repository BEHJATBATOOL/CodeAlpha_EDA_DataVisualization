#  EDA and Data Visualization


## Tasks Completed

### Task : Exploratory Data Analysis (EDA)

The dataset was explored to understand its structure, data types, missing values, duplicate records, sales patterns, and important business insights.

The analysis included:
- Dataset overview
- Missing value analysis
- Duplicate value analysis
- Data cleaning
- Revenue calculation
- Country-wise revenue analysis
- Product revenue analysis
- Time-based revenue analysis
- Customer revenue analysis
- Key findings
The project includes:
- Top 10 Countries by Revenue
- Top 10 Products by Revenue
- Monthly Revenue Trend
- Top 10 Products by Quantity Sold
- Top 10 Customers by Revenue

## Tools and Technologies

- Python
- Pandas

- GitHub

## Dataset

The project uses the Online Retail dataset for sales analysis.

The project demonstrates how exploratory data analysis and data visualization can be used to identify sales trends, high-performing products, important customers, and key markets.
